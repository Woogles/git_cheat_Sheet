# Git Troubleshooting

## What Branch Am I On?

```bash
git branch
```

---

## What Changed?

```bash
git status
```

---

## What Did I Change?

```bash
git diff
```

---

## Undo File

```bash
git restore file.txt
```

---

## Get Latest

```bash
git pull
```

---

## Upload Latest

```bash
git push
```

---

# Panic Checklist

Before doing anything:

```bash
git status
git branch
git log --oneline -10
```

These three commands solve most Git confusion.
