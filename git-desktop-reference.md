# Git Desktop Reference

## Desktop Git Clients

### GitHub Desktop

Good for:

- Beginners
- Visual commits
- Visual branch management
- Visual PR management

Workflow:

```text
Make Changes
     ↓
Review Changes
     ↓
Commit
     ↓
Push
     ↓
Create Pull Request
```

### SourceTree

Good for:

- Large repositories
- Visual history
- Complex branching

### GitKraken

Good for:

- Teams
- Visualizing branches
- Merge conflict resolution

---

# Visual Button Mapping

| CLI | GitHub Desktop |
|------|------|
| git add | Stage |
| git commit | Commit |
| git push | Push Origin |
| git pull | Fetch Origin / Pull |
| git branch | Current Branch |
| git merge | Merge Into Current Branch |
| git clone | Clone Repository |

---

# Rule of Thumb

When something breaks:

```text
CLI = Power Tool

GUI = Visualization Tool
```

Learn CLI first.
Use GUI second.
