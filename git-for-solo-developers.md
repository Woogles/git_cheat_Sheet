# Git for Solo Developers

You are:

- Developer
- Tester
- Reviewer
- Project Manager

Git becomes your memory.

---

# Recommended Workflow

main
 ↓
feature branch
 ↓
test
 ↓
merge

---

# Every Feature

Create branch:

```bash
git switch -c feature-name
```

Work.

Commit often:

```bash
git commit -m "small meaningful change"
```

Merge only when satisfied.
