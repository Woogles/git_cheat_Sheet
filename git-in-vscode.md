# Git in VSCode

VSCode includes Git support built-in.

## Source Control View

Shortcut:

```text
Ctrl + Shift + G
```

Provides:

- Changed Files
- Staging
- Commits
- Branch Switching
- Sync

---

# Common Actions

## Stage File

Click:

```text
+
```

Equivalent:

```bash
git add filename
```

---

## Commit

Type message.

Click:

✓
```

Equivalent:

```bash
git commit -m "message"
```

---

## Push

Click:

```text
Sync Changes
```

Equivalent:

```bash
git push
```
